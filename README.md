# Heroes & Deities TCG

Playable browser client for **Heroes & Deities**, a Greek-mythology trading card game in the spirit of official One Piece TCG clients.

**Play:** open [index.html](index.html) locally, or after GitHub Pages is enabled:
`https://reaper4rent.github.io/heroes-and-deities-tcg/`

Print kit (fronts, backs, ALT, Parallel):
https://github.com/reaper4rent/heroes-and-deities-print-kit

## Starter decks (free)

- **ST-01 Host of Ares** — Paragon: Ares, God of Cinders (5,000)
- **ST-02 Thunderforge** — Paragon: Brontes, God of the Thunderforge (5,000)

Both starters are fully owned from first launch. Additional packs cost credits earned by winning battles.

## Rules (table + digital)

- Each player has **6 HP** on a Health Die. At **0 HP** you lose.
- Characters have **Power**, not individual HP.
- **Divine** is its own 10-card resource deck. First player starts with **2 Divine**.
- Only **Paragons** can Awaken (at 2 HP or less). Awakened art is a unique inset.
- Combat: attacker Power vs defender Power (plus attached Divine, auras, Counters, Guard).
- Commons ~30% in packs. Mythic ~3.5% per pack. Mythic / ALT / Parallel can roll **Foil** or **Holo**.
